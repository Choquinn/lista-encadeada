# Introdução

Esse projeto foi feito no intuito de entender e praticar o conceito de lista encadeada. O programa completo foi feito em C, usando apenas das bibliotecas padrões do C (stdio e stdlib).

# Funções
- createNodule(valor) &#8594; Adiciona um nó em uma lista (recomendado ao iniciar)
- insertFirst(&lista, valor) &#8594; Adiciona um valor no primeiro índice da lista
- insertLast(&lista, valor) &#8594; Adiciona um valor no último índice da lista
- printList(lista) &#8594; Imprime a lista completa no terminal
- listSize(lista) &#8594; Retorna o tamanho da lista
- search(lista, valor) &#8594; Retorna o valor se ele for encontrado, do contrário retorna NULL
- removeFirst(&list) &#8594; Remove o valor que está no primeiro índice
- removeLast(&list) &#8594; Remove o valor que está no último índice
- insertPos(&lista, valor, indice) &#8594; Insere um valor no índice definido
- cleanList(&lista) &#8594; Limpa toda a lista
